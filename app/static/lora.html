This server has no CUDA GPU, so it cannot train or run LoRA voices.

New voice

You will read 14 short sentences, about one minute in total. Each sentence is its own clip, so a mistake only costs one retake. When every sentence is saved, the server trains a voice model for you on its GPU (a few minutes).
Bring your own recordings of one speaker: audio files of one sentence each (1–20 s) and their transcripts. You check how they pair up before anything is uploaded. At least 5 clips; a minute or more works better.
