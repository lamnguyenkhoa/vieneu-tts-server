Calling the API from another service

Base URL: {{BASE}}. The caller must be able to reach this address. By default the server listens only on 127.0.0.1. To accept requests from other machines, set HOST=0.0.0.0 in .env, and also set TTS_API_KEY.

Authentication

If the server has TTS_API_KEY set, send it on every request as Authorization: Bearer <key>. A missing or wrong key returns 401.

Endpoints

MethodPathPurpose
GET/v1/voicesLists the voices. Pass a data[].id as voice. If you leave voice out, the server uses default.
POST/v1/audio/speechTurns text into audio.
POST/v1/voicesClones a voice. Multipart form: name (1–40 letters, digits, spaces or - _ . ( )), file (WAV, FLAC or OGG, 3–8 s, up to 5 MB), optional denoise (default true), gender, description. The new voice is usable right away by its name.
DELETE/v1/voices/{id}Removes a cloned voice. Built-in voices cannot be removed (403).
GET/healthStatus and device (no key needed). Returns 503 while the model loads.

Request body for POST /v1/audio/speech

FieldRequiredMeaning
inputyesThe text to read, up to 20,000 characters.
voicenoA voice id from /v1/voices. Leave it out to use the default voice.
response_formatno"wav" (default) returns one complete file. "pcm" streams raw audio as it is generated.
deviceno"gpu" or "cpu". Leave it out to use the server default (TTS_DEFAULT_DEVICE). The first request for a device that is not loaded yet waits while it loads. The response header X-Device says which device ran the request.
modelnoAccepted for OpenAI compatibility ("vieneu-v3-turbo").

The server reads text exactly as written. It does not convert numbers, dates, times or licence plates to words, so write them out (for example "mười giờ" instead of "10:00").

Which method to use

File (wav): the response arrives after the whole text has been synthesized, as a normal WAV file (48 kHz, mono, 16-bit). Use it when you need to save or send a file.

Stream (pcm): audio starts arriving after about 0.1 s and keeps coming while it is generated. Use it to play speech with the least delay. Both methods take the same total time; only the wait for the first sound differs.

The stream is raw PCM: 16-bit signed little-endian, mono. The sample rate is in the X-Sample-Rate response header (48000). The stream has no file header, so to save it as a file, add a 44-byte WAV header with that rate. A chunk can end halfway through a 2-byte sample; if so, carry the odd byte into the next chunk.

Stream method

# Raw PCM to a file (-N turns off buffering so bytes arrive as they are generated)
curl -N -X POST {{BASE}}/v1/audio/speech \
  -H "Authorization: Bearer {{KEY}}" \
  -H "Content-Type: application/json" \
  -d '{"voice": "{{VOICE}}", "input": "Xin chào, đây là thông báo thử.", "response_format": "pcm", "device": "{{DEVICE}}"}' \
  --output speech.pcm

# Or play it live with ffplay (part of ffmpeg): replace the last line with
#   --output - | ffplay -f s16le -ar 48000 -ch_layout mono -nodisp -autoexit -
import wave
import requests

with requests.post(
    "{{BASE}}/v1/audio/speech",
    headers={"Authorization": "Bearer {{KEY}}"},
    json={"voice": "{{VOICE}}", "input": "Xin chào, đây là thông báo thử.", "response_format": "pcm", "device": "{{DEVICE}}"},
    stream=True,
    timeout=120,
) as res:
    if not res.ok:
        raise RuntimeError(res.json()["error"]["message"])
    rate = int(res.headers.get("X-Sample-Rate", 48000))
    with wave.open("speech.wav", "wb") as out:  # wave writes the WAV header for you
        out.setnchannels(1)
        out.setsampwidth(2)
        out.setframerate(rate)
        for chunk in res.iter_content(chunk_size=4096):
            # Play or forward each chunk here as it arrives (sounddevice, a websocket...).
            out.writeframes(chunk)
// Plays the stream as it arrives with the Web Audio API (no library).
// A page on another domain needs that domain in ALLOWED_ORIGINS on this server.
async function streamSpeech(input, voice) {
  const res = await fetch("{{BASE}}/v1/audio/speech", {
    method: "POST",
    headers: { "Authorization": "Bearer {{KEY}}", "Content-Type": "application/json" },
    body: JSON.stringify({ input, voice, response_format: "pcm", device: "{{DEVICE}}" }),
  });
  if (!res.ok) throw new Error((await res.json()).error.message);
  const rate = Number(res.headers.get("X-Sample-Rate")) || 48000;
  const ctx = new AudioContext();
  const reader = res.body.getReader();
  let nextTime = 0, carry = null;
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    let bytes = value;
    if (carry !== null) { bytes = new Uint8Array([carry, ...value]); carry = null; }
    if (bytes.length % 2) { carry = bytes[bytes.length - 1]; bytes = bytes.subarray(0, -1); }
    if (!bytes.length) continue;
    const view = new DataView(bytes.buffer, bytes.byteOffset, bytes.byteLength);
    const buffer = ctx.createBuffer(1, bytes.length / 2, rate);
    const ch = buffer.getChannelData(0);
    for (let i = 0; i < ch.length; i++) ch[i] = view.getInt16(i * 2, true) / 32768;
    const src = ctx.createBufferSource();
    src.buffer = buffer;
    src.connect(ctx.destination);
    if (nextTime < ctx.currentTime) nextTime = ctx.currentTime + 0.12;  // small buffer against gaps
    src.start(nextTime);
    nextTime += buffer.duration;
  }
  return ctx;  // ctx.close() stops playback; reader.cancel() also tells the server to stop generating
}

Clone a voice

curl -X POST {{BASE}}/v1/voices \
  -H "Authorization: Bearer {{KEY}}" \
  -F "name=My voice" \
  -F "file=@reference.wav" \
  -F "gender=female"

# Remove it again
curl -X DELETE "{{BASE}}/v1/voices/My%20voice" -H "Authorization: Bearer {{KEY}}"
import requests

with open("reference.wav", "rb") as f:
    res = requests.post(
        "{{BASE}}/v1/voices",
        headers={"Authorization": "Bearer {{KEY}}"},
        data={"name": "My voice", "gender": "female", "denoise": "true"},
        files={"file": ("reference.wav", f, "audio/wav")},
        timeout=120,
    )
if not res.ok:
    raise RuntimeError(res.json()["error"]["message"])
print(res.json()["id"])  # pass this as "voice" to /v1/audio/speech

Errors

Errors are JSON in OpenAI's format: {"error": {"message": "...", "type": "invalid_request_error", "code": 400}}.

StatusMeaning
400Bad request: empty input, unknown voice, or unsupported response_format.
401Missing or wrong API key.
404Deleting a cloned voice that does not exist.
409Cloning with a name that is already taken.
413Clone clip larger than 5 MB.
429Server busy. Retry after the number of seconds in the Retry-After header.
503Model still loading.
